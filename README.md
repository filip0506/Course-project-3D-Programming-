# Project

### 3D Programming — Direct3D 11 Rendering Project

A C++ 3D rendering application developed as part of the DV1568 — 3D Programming course at Blekinge Institute of Technology (BTH) in autumn 2020.

The project explores real-time rendering techniques using Direct3D 11 (D3D11), featuring a 3D scene with terrain, dynamic lighting, shadows, normal mapping, and interactive objects.

## Features

- Deferred rendering
- Custom OBJ model loading
- Height-map terrain rendering
- Normal mapping
- Shadow mapping
- Geometry shader back-face culling
- Mouse picking
- Animated water
- Interactive gameplay

## Technologies

- C++
-  Direct3D 11 (D3D11)
-  HLSL shaders
-  Visual Studio
-  Real-time 3D graphics and GPU programming

## Controls

### Camera

| Key | Action |
|---|---|
| Arrow keys | Move the camera |
| Space | Move the camera up |
| Shift | Move the camera down |
| R | Toggle terrain collision |
| Esc | Exit the application |

### Lighting

| Key | Action |
|---|---|
| W / A / S / D | Move the light |
| Z / X | Move the light vertically |
| Q | Reset the light position |
| E | Move the light to the opposite side |

### Scene Interaction
| Key | Action |
|---|---|
| G	| Enable normal mapping| 
| H	| Disable normal mapping| 
| V / B	| Move the cube in front of the camera| 

### Purpose

The goal of this project was to gain practical experience implementing established rendering techniques, working with the Direct3D 11 graphics pipeline, writing shaders, and rendering a more complex interactive 3D environment.

The project was developed as an academic assignment for DV1568 — 3D Programming, Blekinge Institute of Technology, during the autumn semester of 2020.
